# Pesquisa de Atendimento - TudoWeb

## Objetivo

Programa desenvolvido em Python para realizar uma pesquisa de satisfação com clientes da empresa TudoWeb.

O programa coleta:

* Nome
* Idade
* Opinião sobre o atendimento

As opções de opinião são:

* 1 - Excelente
* 2 - Bom
* 3 - Ruim

## Funcionamento

O programa utiliza uma estrutura de repetição para realizar a pesquisa com 50 entrevistados.

Ao final, mostra:

* Quantidade de respostas EXCELENTE
* Quantidade de respostas BOM
* Quantidade de respostas RUIM

## Linguagem utilizada

🐍 Python

## Como executar

1. Abra o arquivo `.py` em um editor de código.
2. Execute o programa.
3. Digite os dados solicitados.
4. Escolha uma das opções de atendimento.
